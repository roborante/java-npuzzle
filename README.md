## 🚀 Download & Esecuzione

Se non desideri compilare il codice sorgente, puoi scaricare l'eseguibile pre-compilato direttamente da qui:

* 📦 **Download dal Google Drive ([ npuzzle.jar ](https://drive.google.com/file/d/1cJy0BIhLQwozqUjOLbIlYjCM912P2k2C/view?usp=drive_link))**

### Requisiti
* Java Runtime Environment (JRE) versione 8 o superiore.

Avviarlo da terminale con il comando:
```bash
java -jar nPuzzle.jar
```
